## Stanford Alpaca

**Summary**: Fine-tuned LLaMA model from Stanford trained on 52K GPT-3-generated instruction-following examples; popularized the Alpaca prompt template for instruction fine-tuning.

| Attribute | Value |
|---|---|
| Base model | LLaMA (Meta) |
| Training data | 52K (instruction, response) pairs generated by GPT-3 (text-davinci-003) |
| Prompt template | `### Instruction / ### Input (optional) / ### Response` |
| Released | March 2023 |
| License | Non-commercial (inherits LLaMA restrictions) |

## Alpaca Prompt Template

```
Below is an instruction that describes a task. Write a response that appropriately completes the request.

### Instruction:
{instruction}

### Input:
{input}

### Response:
{response}
```

- `### Input` is optional — omitted when no extra context is needed
- Template must be used identically at training and inference time
- Many later models (Vicuna, etc.) adopted variations of this format

## Significance

- Demonstrated cheap instruction-following fine-tuning (~$600 of GPT-3 API calls)
- Popularized the idea of using a stronger LLM to generate training data for a weaker one (self-instruct)
- Template became a de-facto starting point; not a universal standard
